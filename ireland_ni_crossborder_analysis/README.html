Ireland Nearest Analysis

A QGIS plugin for nearest feature analysis using Irish Transverse Mercator (EPSG:29903). The plugin integrates with the EPA API to retrieve Irish environmental datasets.

Features

  • Nearest feature analysis
  • Distance calculation
  • Bearing calculation
  • CSV export of results
  • EPA API dataset integration

Requirements

  • Project CRS: EPSG:29903 (Irish Transverse Mercator)
  • Internet connection for EPA API access

Contains data from the Environmental Protection Agency (EPA), licensed under CC BY 4.0.
